# Endless Sky Takeover

**gta5** × Endless Sky · visual · idea by the team

Bring Endless Sky into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Sandy Shores into an Endless Sky spaceport: shuttles land, alien pirates have shields, and I shot a raider ship out of the sky for credits.

## Install

Put the folder in your FiveM server's resources folder as sigf_mod, add 'ensure sigf_mod' to server.cfg, then join the server. Everything runs by itself near the airfield, no extra files needed.
